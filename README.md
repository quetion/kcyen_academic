# 顏廣杰｜個人學術網站

這是顏廣杰（Kuang-Chieh Yen）的雙語個人學術網站，版面參考 Academic Pages 的學者資料卡與多頁資訊架構，並以不需要額外建置工具的靜態網站方式發布至 GitHub Pages。

## 網站頁面

- `index.html`：個人簡介與近期動態
- `publications.html`：期刊論文與工作論文
- `teaching.html`：目前課程與授課紀錄
- `students.html`：學生指導與推薦函資訊
- `service.html`：期刊審查與演講
- `cv.html`：學術履歷、研究計畫與獲獎

共用外觀與互動分別位於 `styles.css` 和 `script.js`。網站支援中英文、明暗模式、手機版導覽與 GitHub Pages 自動發布。

社群分享預覽圖位於 `og-academic-pages.png`。

## 更新網站

修改完成後執行：

```bash
git add .
git commit -m "更新網站內容"
git push
```

推送至 `main` 後，GitHub Pages 會自動重新發布。
