# 顏廣杰｜個人學術網站

這是一個為 GitHub Pages 準備的雙語個人學術網站，內容由原 Google Sites 網站整理而來。

## 發布方式

1. 在 GitHub 建立一個新的公開 repository。
2. 將此資料夾的內容推送到 `main` 分支。
3. 在 repository 的 **Settings → Pages → Build and deployment** 中，將 **Source** 設為 **GitHub Actions**。
4. 等待網站自動發布；之後每次更新 `main` 分支，網站都會同步更新。

若 repository 名稱為 `你的帳號.github.io`，網址會是 `https://你的帳號.github.io/`；其他名稱則會是 `https://你的帳號.github.io/repository名稱/`。

## 維護內容

- 網站內容：`index.html`
- 外觀與手機版：`styles.css`
- 中英文切換：`script.js`
- 分享預覽圖：`og.png`

網站不依賴資料庫或額外套件，GitHub Pages 可直接發布。
